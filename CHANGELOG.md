# Changelog

## 1.0.0 — 2026-10-19

First open-source release, renamed from SANDLAB to **PIXL.LAB**.

- Removed the CrazyGames SDK: no ads, banners, analytics or platform lock.
- All Special materials (Cloner, Void, Wind, Freeze ray, Antimatter, Black hole) are available from the start.
- Recipe reveal in the Lab notebook is free, with a 3-minute cooldown.
- Saves and progress use plain `localStorage` under the `pxl_` prefix.
- Split the single HTML file into `css/` and `js/` modules.
- Added favicon, meta tags and a GitHub Pages workflow.
